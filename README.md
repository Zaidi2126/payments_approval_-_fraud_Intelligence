# deriv_guard

Django + Django REST Framework backend for payment approval and fraud intelligence.

## Requirements

- Python 3.11+

## Setup

1. **Create a virtual environment**

   ```bash
   python -m venv .venv
   source .venv/bin/activate   # On Windows: .venv\Scripts\activate
   ```

2. **Install dependencies**

   ```bash
   pip install -r requirements.txt
   ```

3. **Configure environment (optional)**

   Copy `.env.example` to `.env` in the project root and set values as needed:

   - `SECRET_KEY` — Django secret (defaults to a dev key if unset)
   - `DEBUG` — Set to `True` for development
   - `SLACK_WEBHOOK_URL` — Optional; required for `python manage.py send_daily_slack_summary` to post to Slack
   - `OPENAI_API_KEY` — Optional; when set, **reasons** and **counterfactuals** in payout decisions are generated by the LLM. If unset, deterministic fallback text is used.
   - `OPENAI_MODEL` — Optional; e.g. `gpt-4o-mini` (default if unset). `OPENAI_TIMEOUT_SECONDS` and `OPENAI_MAX_OUTPUT_TOKENS` are also supported (see `.env.example`).

   **Important:** The LLM is used only for narrative explanations (reasons and counterfactuals). Approve / review / block decisions and risk scores remain **fully deterministic** (rules and scoring engine) for safety and speed.

4. **Run database migrations**

   ```bash
   python manage.py migrate
   ```

5. **Run the development server**

   ```bash
   python manage.py runserver
   ```

   The API will be available at `http://127.0.0.1:8000/`.

## API

- **GET /health** — Health check. Returns `{"status": "ok"}`.
